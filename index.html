    VietUrban Supermarket Simulator

    Nine kinds of agent

    Customers run a state machine: browse, judge prices, queue, pay or steal, then rate the store 1–5 stars. Shelf stockers pick the most urgent shelf by utility score; guards chase thieves; cleaners find the nearest mess.

    Giza: The Great Pyramid in 3D

    A browser model of Khufu's pyramid built from 22,994 individual stones placed to archaeological survey data. Take it apart layer by layer, watch twenty years of construction, walk the passages at true scale, rediscover the Big Void with simulated muons, and ask an AI guide that drives the scene itself.

    LAYER 1 · RENDERING

    Solid cross-sections

    Every stone is drawn into the stencil buffer with an invert op; odd parity means "inside rock", so the cut is filled with mortar-jointed masonry and the chambers show up as real cavities. Instanced meshes, PBR lit from the sky model, render-on-demand with cached shadows.

    LAYER 2 · SIMULATION

    Science you can check

    13,200 rays traced through the real geometry with Poisson noise reproduce the ScanPyramids Big Void above 5σ. IAU 1976 precession plus proper motion puts Alnitak on the King's Chamber south shaft around 2476 BCE.

    LAYER 3 · AI AGENT

    An AI that drives the scene

    A Claude tool-use loop with 7 scene tools: it flies the camera, cuts the pyramid open, runs the muon lab and the night sky, then explains. Every call is shown in an agent trace and graded by a 20-case eval suite.

    • Layer-by-layer teardownA scripted sequence lifts the capstone, peels the Tura casing course by course from the top, then separates the core to reveal the chambers.
    • Construction timelineTwenty years paced by stone volume, with four ramp hypotheses (straight, zigzag, spiral, Houdin's internal ramp) and live length, material and crew estimates.
    • First-person walkTrue-scale passages lit by a flickering torch; you crouch automatically in the 1.2 m ascending passage, and footsteps echo to the size of each room.
    • AI code studioDescribe a change in plain words and Claude writes JavaScript against the page's own giza API. Runs in a sandbox; on error the AI reads the stack and fixes it.
    • Agent evaluation20 test cases check tool choice, arguments and order, forbidden calls, required facts, language and length, with pass rate per category and JSON export.
    • Public AI, safelyA Cloudflare Worker keeps the API key server-side, allows only this origin, rate-limits per IP and picks the model, so the AI works on the public GitHub Pages site.

    Automated Daily News Aggregator

    Candidate & team representative. An AI pipeline that collects 1,000+ breaking news articles a day from VnExpress, Tuổi Trẻ and Thanh Niên, groups duplicates and writes short summaries.

    STEP 1 · ETL

    Scrape & structure

    Python scrapers (BeautifulSoup, Selenium) pull RSS and web sources, clean unstructured text and load it into PostgreSQL.

    GPT-3.5-turbo with custom prompts handles zero-shot topic classification and concise summaries.
